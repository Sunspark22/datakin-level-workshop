What the preview shows

Layout and collision shapes. Backgrounds, enemy behavior, boss attacks and some theme events belong to the engine. A test ROM shows the real result. Insert section shifts supported scripted events along with the route. Moving individual objects does not rewrite their scripts.

This ROM has fixed storage. Counts below show used / available. Red counts must be reduced before applying or building. Summoned foes reserve enemy slots. Dense scenes can still slow down.

Your first edit

  1. Choose a stage, or start a blank draft.
  2. Choose Platform, then drag to draw. Click for enemies and markers.
  3. Use Select / move to drag things. Resize using the lower-right square, or change the numbers at the right.
  4. Save draft keeps a dated copy. Export JSON makes a layout file you can share.
  5. Apply to workspace applies your finished stage to future ROM exports from this workspace and saves the old layout as a backup in the draft list. Repeat for other finished stages.
  6. Build edited ROM combines all applied stages with your open draft. Download it or find it in output/Datakin-Edited.gba. Open it in your own emulator, start a new test save and enter the chosen stage from the hub. Your original ROM stays untouched.

Scroll bars move around the level. Space + drag also pans. Click the overview to travel quickly. Ctrl+Z/Y undo/redo, Ctrl+D duplicates, Delete removes, Escape selects. Shift temporarily bypasses snapping. Jump guide shows an approximate ordinary jump, not a guarantee.

Checkpoints place Ket's feet at the marker. The collectible and boss rewards stay tied to their stage slot. Platform flags in the inspector mark disappearing platforms, lava rafts or boss floor pieces.

Enemies and bigger maps

Choose Enemy, then the Enemy type on the left before placing it. Select an existing enemy to change its type on the right.

Stage settings has Add space below and Add space above for every environment. Draw Cloud platforms for a climb: Ket jumps through them from below and lands on top.

To extend the route in the middle, set Insert at X and Section width, or choose Use view center, then Insert section. The right side moves together; crossing ground stretches. Undo reverses the whole insert. Moving-platform travel stays as set.
